Comparative Machine Learning Algorithms
1. Logistic Regression
Linear Probabilistic Classifier

Estimates log-odds of passing using a sigmoid function: $\sigma(z) = \frac{1}{1 + e^{-z}}$. Combined with StandardScaler to ensure scale invariance across attendance (0-100) and marks (0-50).

2. Decision Tree
Non-Parametric Rule Learning

Splits feature space recursively based on Gini Impurity to construct intuitive if-then decision thresholds. Constrained with max_depth=5 to prevent overfitting on sample boundaries.

3. Random Forest
Ensemble Bagging Classifier

Builds an ensemble of 100 decorrelated decision trees with bootstrap aggregation. Reduces variance and prevents single-tree bias when mapping borderline academic features.

4. K-Nearest Neighbors
Instance-Based Learning

Classifies a query student based on the majority outcome of the $k=5$ most similar historical student vectors in normalized Euclidean space via StandardScaler.

Faculty Viva & Review Preparation Guide

Hardcoded rules fail to capture non-linear trade-offs between features (for instance, a student with slightly lower attendance who studies 6 hours daily and scores high internal marks). Machine learning classification models learn continuous multi-dimensional boundary representations and provide probabilistic confidence scores.

We utilize Scikit-learn Pipeline objects. Feature scaling (such as StandardScaler) is fitted strictly on the training partition (X_train) during pipe.fit(). The test set (X_test) and incoming student inferences only undergo transformation using the learned training statistics, preventing test-set knowledge from contaminating the model.

In empirical machine learning ("No Free Lunch Theorem"), no single algorithm dominates all problem domains. Our application trains Logistic Regression, Decision Trees, Random Forest, and KNN simultaneously on identical stratified splits, computes F1-scores, and automatically deploys the actual empirical winner to production.

Predictions are explicitly categorized as decision-support insights rather than deterministic verdicts. The system avoids labeling students as "Fail" or "Weak", instead using supportive terminology ("May Need Support") alongside actionable pedagogical recommendations (mentoring, study routines, remedial assignments). Teachers remain the final decision-makers.
