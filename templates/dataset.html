Expected CSV Schema

The system expects exactly these headers:

student_id,attendance,study_hours,marks,result
Field Specifications:
  • student_id: Unique text identifier (e.g., STU001)
  • attendance: Float/Integer in range 0 to 100
  • study_hours: Float/Integer in range 0 to 24
  • marks: Internal score in range 0 to 50
  • result: Target classification label (Pass or Fail)
Machine Learning Integrity: Only ground-truth institutional labels must be uploaded. Model predictions should never be reused as training labels.
